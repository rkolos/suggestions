# Режим последовательного выполнения тасок

## Как запустить

Скопируй и вставь в чат Composer:

```
Запусти режим последовательного выполнения тасок из папки about.

Стартовая таска: about/1_7.md
Порядок: по имени файла (1_7 → 1_8 → 1_9 → 2_1 → … → 6_5)

Для каждой таски:
1. **Plan** — прочитай таску, создай краткий план реализации (файлы, шаги, проверки)
2. **Agent** — выполни план
3. **DoD** — проверь все критерии из раздела "Критерии выполнения (Definition of Done)"
4. Переход к следующей таске

Не останавливайся между тасками. Выполняй все DoD-действия сам (миграции, тесты, .env и т.п.).
```

Либо коротко:

```
@about/SEQUENTIAL_MODE.md — выполни таски из about начиная с 1_7
```
