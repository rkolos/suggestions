# TASK-6.5: Сценарий D - Discord-интеграция (Corde)

## Контекст и цель задачи

Предыдущие тесты (6.1–6.4) проверяли API и внутреннюю логику, но они не гарантируют, что бот реально отправляет сообщения в Discord или что кнопки на этих сообщениях работают. Чтобы проверить "последнюю милю" интеграции, мы будем использовать **Corde** — фреймворк для тестирования Discord-ботов "извне".

Corde запускает вспомогательного бота-тестера, который имитирует действия реального пользователя на тестовом сервере, отправляет команды нашему боту и проверяет его ответы. Это самый надежный способ убедиться, что Discord API не блокирует наши запросы и права доступа (Permissions) настроены верно.

## Что нужно сделать разработчику (Action Items)

### 1\. Подготовка инфраструктуры Corde

-   Установить зависимости: `npm install corde --save-dev`.
-   Создать файл конфигурации `corde.config.json`.
-   **Настройка окружения:** Секреты (токены ботов, `guildId`, `channelId`) хранить в файле **`.env.test`** (и в CI secrets при необходимости). Файл **`corde.config.json`** должен использовать **интерполяцию переменных окружения** для подстановки этих значений.
-   **Запуск в CI:** Запуск `test:corde` выполнять **вручную** или по тегу (например, только при пуше с тегом). При отсутствии секрета в окружении (например, `CORDE_BOT_TOKEN`) тест должен **автоматически пропускаться** (skipped), а не падать.
-   В конфиге указать: `botToken` (наш бот), `cordeBotToken` (тестер), `guildId`, `channelId` — значения берутся из `.env.test`.

### 2\. Сценарий 1: Полный жизненный цикл и визуализация (Status Cycle)

Этот сценарий проверяет, как бот обновляет Embed при смене состояний в БД.

-   **Шаг 1.1 (Создание):** Вызвать `/suggest` через бота-тестера. Проверить получение ответа (Modal/Ephemeral).
-   **Шаг 1.2 (Публикация):** Через REST API перевести идею в `OPEN`.
    
    -   _Проверка в Corde:_ Убедиться, что в канале появился Embed с цветом `OPEN` и создана ветка (Thread).
-   **Шаг 1.3 (В работе):** Через REST API сменить статус на `IN_PROGRESS`.
    
    -   _Проверка в Corde:_ Убедиться, что Embed обновился (сменил цвет/текст), а не создался новый.
-   **Шаг 1.4 (Завершение):** Через REST API сменить статус на `COMPLETED`.
    
    -   _Проверка в Corde:_ Убедиться, что Embed стал "зеленым", а ветка (Thread) была заблокирована (Locked).

### 3\. Сценарий 2: Интерактивное голосование и синхронизация

-   **Шаг 2.1 (Upvote):** Бот-тестер нажимает кнопку 👍 под Embed.
    
    -   _Проверка:_ Лейбл кнопки изменился на "👍 1". Бот прислал скрытое подтверждение.
-   **Шаг 2.2 (Toggle):** Бот-тестер нажимает кнопку 👍 еще раз.
    
    -   _Проверка:_ Лейбл кнопки вернулся в состояние "👍 0" (снятие голоса).
-   **Шаг 2.3 (Change Mind):** Бот-тестер нажимает 👎.
    
    -   _Проверка:_ Лейбл 👍 — "0", лейбл 👎 — "1".

### 4\. Сценарий 3: Безопасность и Модерация (Negative Cases)

Проверка того, что бот реально соблюдает ограничения для забаненных пользователей.

-   **Шаг 3.1 (Бан):** Через REST API забанить ID бота-тестера.
-   **Шаг 3.2 (Действие под баном):** Бот-тестер пытается нажать кнопку голосования или вызвать `/suggest`.
    
    -   _Проверка:_ Бот присылает Ephemeral-сообщение об ошибке "Вы забанены". Состояние кнопок в канале **не** меняется.
-   **Шаг 3.3 (Разбан):** Разбанить тестера через API и повторить действие. Убедиться, что доступ восстановлен.

### 5\. Сценарий 4: Слияние и Дубликаты (Merge Flow)

-   **Шаг 4.1 (Подготовка):** Создать две идеи (Идея А и Идея Б).
-   **Шаг 4.2 (Слияние):** Через REST API слить Идею Б в Идею А.
-   **Проверка в Corde:**
    
    -   Найти сообщение Идеи Б. Убедиться, что Embed обновился: статус сменился на "Дубликат", кнопки голосования удалены (или отключены), и в тексте появилась ссылка на Идею А.
    -   Проверить, что в ветке Идеи Б появилось прощальное сообщение от бота.

### 6\. Сценарий 5: Публичные ответы (Admin Responses)

-   **Действие:** Через REST API добавить публичный комментарий от имени админа.
-   **Проверка в Corde:** Бот-тестер заходит в ветку (Thread) предложения и проверяет, что там появилось сообщение от нашего бота с текстом комментария и плашкой `[ОФИЦИАЛЬНЫЙ ОТВЕТ]`.

-   \[ \] Реализованы все 5 сценариев (Жизненный цикл, Голосование, Баны, Слияние, Комментарии).
