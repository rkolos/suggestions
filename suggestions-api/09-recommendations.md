# Рекомендации по документу для разработчика

1. Оформить как единый справочник (например этот набор файлов в папке `suggestions-api`) и при необходимости экспортировать в OpenAPI/Swagger.
2. **Реализовано в этой документации:** для каждого эндпоинта указаны метод и путь, query/body, коды ответов и примеры JSON запроса/ответа (разделы [03-conventions.md](03-conventions.md) и файлы 04–06).
3. **Реализовано:** коды ошибок (400, 401, 403, 404, 409) и единый формат тела ошибки описаны в [03-conventions.md](03-conventions.md)#формат-ошибок.
4. **Реализовано:** формат пагинации (offset: page/limit, лимиты по умолчанию; опционально cursor для комментариев) описан в [03-conventions.md](03-conventions.md)#пагинация.
5. **Реализовано:** при `grouped=true` ответ GET suggestions — массив элементов типа cluster или suggestion; различение по полю `type: "cluster"` у кластера (master, children, totalDuplicates) описано в [03-conventions.md](03-conventions.md)#формат-ответа-при-groupedtrue-get-suggestions.
6. **Реализовано:** источник текущего пользователя (Authorization: Bearer &lt;token&gt; или cookie сессии) и использование при создании предложения и комментариев описаны в [03-conventions.md](03-conventions.md)#аутентификация-и-текущий-пользователь.
